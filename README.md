# Frander Centeno

Full-stack developer based in Costa Rica. I build web apps and data dashboards for small businesses, public institutions and startups.

*Desarrollador fullstack en Costa Rica. Construyo aplicaciones web y dashboards de datos.*

## What I build

**Web apps.** React, Next.js and NestJS on the front and back, Supabase for data and auth, Tailwind for UI. Responsive and tested before delivery.

**Data dashboards.** Python pipelines that turn messy public files into clean models and dashboards that answer concrete questions.

Recent work: public site and admin dashboard for the Municipality of Nicoya, and an inventory system for a rural water utility.

## Featured projects

| Project | What it does | Stack |
|---|---|---|
| [turismo-cr](https://github.com/Frandercc1234/turismo-cr) | Dashboard of international arrivals to Costa Rica for a Guanacaste tourism chamber. Parses official ICT PDF reports and checks every table against the published totals. | Python, DuckDB, Streamlit |
| [asada-gamalotal-inventario](https://github.com/Frandercc1234/asada-gamalotal-inventario) | Inventory system for ASADA Gamalotal, a rural water utility. | Next.js, Supabase, Tailwind |
